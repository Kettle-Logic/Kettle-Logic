# Settings and Shortcuts

This page shows you how to change Kettle Logic's settings and find its keyboard shortcuts.

## Open Settings

Click the **Settings** button at the bottom of the navigation pane, or press **Ctrl+,**.

## Change a setting

| Setting | What to do |
|---|---|
| **Simple mode** | Turn it on to see only the basics. Turn it off to see every tab. |
| **Group recipe tabs (experimental)** | Turn it on to group the tabs under Recipe, Ingredients, Process, and Results. |
| **Autosave changes** | Turn it on to save each change to the recipe's file as you make it. |
| **Confirm before deleting a recipe** | Turn it off to delete recipes without a confirmation. |
| **Units** | Pick metric or US. |
| **Default brewing system** | Pick the system that new recipes start with. |
| **Recipe Folder** | Choose the folder where new recipes are saved. |
| **Keep display on** | Turn it on to keep the screen awake while you brew. |

## Keyboard shortcuts

| Action | Shortcut |
|---|---|
| New recipe | Ctrl+N |
| New recipe from a style | Ctrl+Shift+N |
| Open | Ctrl+O |
| Save | Ctrl+S |
| Save As | Ctrl+Shift+S |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Show or hide Simple Mode | Ctrl+Alt+M |
| Settings | Ctrl+, |
| Kettle Logic Help | F1 |
| Go to a recipe tab, first to ninth | Ctrl+1 to Ctrl+9 |

## Open this guide again

Click **Help ▸ Kettle Logic Help**, or press **F1**.
